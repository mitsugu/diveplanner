# Dive Planner

## これは何？
　潜水計画を立てるために必要な計算を簡便化するものです。電卓を叩いて計算していた各種計算作業を簡略化することを目的に作成した Web アプリケーションです。  
　全ファイルをダウンロードして、index.html をファイラーでクリックすれば、**電波が届かない環境**でも使うことができます。  

　[Dive Planner](https://mitsugu.github.io/diveplanner/) <=　電波が届くところではこのリンクをクリックすることで使用することができます。  

## 説明
　ダイビングカリキュレーターの説明です。  
　現在以下の４つの計算を行うことができます。電卓を叩く労力を減らすのが目的です。  

### 1. EAN (ナイトロックス) 計算機
#### これは何:
　ナイトロックスを使用する場合に計算する必要がある MOD、PO2、EAD を求めます。  

#### 使用タイミング:
　潜水計画時に使います。  

#### 入力:
* FO2: 酸素濃度
* PO2: 最大許容酸素分圧
* 予定水深

#### 計算結果:
* MOD: 最大許容水深
* PO2: 予定水深での酸素分圧
* EAD: 空気換算深度


### 2. RMV (呼吸ガス消費量) 計算機
#### これは何:
　そのダイブの呼吸ガス消費量を計算します。  

#### 使用タイミング:
　潜水修了後のログ付など  

#### 入力:
* 開始残圧
* 終了残圧
* タンク容量
* 潜水時間
* 平均水深

#### 計算結果:
* 消費圧力
* 消費空気量
* 平均水深の絶対圧
* RMV

### 3. ガス管理計画計算機
#### これは何:
　RMV に基づくリターンプレッシャー、50bar ルールに基づくリターンプレッシャー、1/3 ルールに基づくリターンプレッシャーなどを計算することができます。  

#### 使用上の注意:
　レクリエーショナル・ダイビングを想定したものであり、無減圧潜水を前提とします。また減圧用ガスやステージボトルなど、複数のガスを使用するテクニカルダイビングには対応していません。  

#### 使用タイミング:
　潜水計画時に使います。  

#### 入力:
* RMV: 呼吸ガス消費量
* 緊急時消費率ファクター  
バディとあなたのストレス消費増を統合した倍率です (例: 3.0 or 4.0)。
* 初期残圧
* タンク容量
* 最大水深
* 最大浮上速度
* 安全停止時間
* アンカーへの推定帰還時間
* M-Gas 固定下限  
50bar ルールや 1/3 ルールを採用する際の残圧を入力します。このデータが 0 や空欄以外の場合は RMV に基づく計算を行います。

#### 計算結果:
　この計算機では、残圧を「通常の帰路で使用するガス」と「緊急時のために残しておくガス」に分けて考えます。  

##### Minimum Gas（M-Gas）
　緊急事態が発生した場合に備えて、最後まで残しておくガスです。  
　最大水深から浮上を開始し、安全停止を経て水面へ到達するまでに必要となるガスを、通常時より増加した緊急時のガス消費量を想定して計算します。  
　M-Gas は通常の潜水中に使用することを前提としたガスではありません。バディへのガス供給や、緊急時のストレスによる呼吸量増加などに対応するための予備ガスです。  
　通常は計算された M-Gas を使用しますが、「M-Gas 固定下限」に 0 より大きい値を入力した場合は、計算値にかかわらず、その入力値を最終的な M-Gas として使用します。  

##### Return Gas（R-Gas）
　最遠点からアンカーなどの浮上地点へ戻り、そこから浮上して安全停止を行うまでに必要と見積もられるガスです。  
　R-Gas は通常時の RMV を基準として計算します。  
　この計算機では、
* 最遠点からアンカーまでの推定帰還時間
* 最大水深から安全停止深度までの浮上時間
* 安全停止時間
を帰路に必要な時間として計算に含めます。  
　R-Gas は、異常が発生していない通常の帰路で使用することを想定したガスです。  

##### Turn Pressure（T-Gas）
　往路を終了し、帰路を開始する残圧です。  
　T-Gas は、  
**T-Gas = M-Gas + R-Gas**  
として求めます。  
　つまり、
* **M-Gas は残しておくガス**
* **R-Gas は帰るために使うガス**
* **T-Gas は帰り始める残圧**
という関係になります。  
　したがって、往路で計画上使用できるガスは、  
**初期残圧 − T-Gas**  
です。  
　残圧が T-Gas に達したら、そこからさらに潜水を継続するのではなく、往路を終了して帰路へ移ります。  

##### T-Gas は「限界残圧」ではありません
　T-Gas は、「この残圧まで使ってよい」という意味の限界値ではありません。  
　実際のガス消費量が計画より多い、流れが強くなった、帰路に時間がかかりそう、呼吸が乱れているなど、計画時より条件が悪化した場合は、T-Gas に到達する前であっても早めに折り返す必要があります。  
　ガス管理は計算値に残圧を合わせるためのものではなく、実際の状況に応じて十分なガスを残したまま潜水を終了するためのものです。  

##### この計算について
　この計算機は、入力された RMV、緊急時消費率ファクター、最大水深、浮上速度、安全停止時間、推定帰還時間などから、ガス管理計画の目安を求めるものです。  
　計算結果は潜水の安全を保証するものではありません。実際の潜水では、海況、流れ、潜水経路、使用器材、バディのガス消費量、退出方法、そのダイビングポイント固有の条件などを含めて計画してください。  

### 4. GTR (Gas Time Remaining) 計算機
#### これは何:
　現在の残圧と水深から、安全に浮上を開始しなければならない限界時間を計算します。  

#### 使用タイミング:
　潜水計画時に使います。  
　本来は GTR はダイブコンピュータがトランスミッタなどから得られるデータをもとにして、水中でリアルタイム計算するものですが、この計算機では潜水計画で利用する想定にしています。  
　現在水深を想定される平均水深にすることで、潜水可能時間を概算するために作成しました。  

#### 入力:
* 水面到達時予備圧 (50bar ルールなら 50)
* 初期充填圧 (メモ。計算には未使用)
* タンク容量
* RMV
* 現在の残圧
* 現在の水深 (ここに想定平均水深を入れます)
* 最大浮上速度
* 安全停止時間

#### 計算結果:
* GTR (滞在可能時間)
* これまでに消費したガス量
* 浮上に必要なガス量
* 現在水深での消費率 (RMV ではない)
